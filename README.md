## About

Software engineer based in Mogadishu, working across **product engineering** at [Kaabeup](https://github.com/kaabeup) and [Waagefaal](https://github.com/waagefaal). I care about clean architecture, reliable APIs, and solutions that hold up in real production environments — including fintech, education, and language technology.

As a **Junior Cybersecurity Engineer**, I am building practical skills in reconnaissance, traffic analysis, web app testing, and Linux-based security tooling while applying secure coding habits in every project I ship.

### What I focus on

- **Full-stack web & mobile** — React/TypeScript, Flutter, MERN-style APIs and SPAs
- **Backend & data** — REST/GraphQL APIs, Oracle, PostgreSQL, MySQL, MongoDB
- **AI & language tech** — speech, agents, and practical ML integrations
- **Junior cybersecurity** — Kali tooling, networking basics, OWASP-minded testing
